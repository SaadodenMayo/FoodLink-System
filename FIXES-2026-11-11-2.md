# FoodLink integration fixes

- Publish food posts as the signed-in Owner role without requiring separate admin approval.
- Persist owner logo/business branding and propagate it to all current food cards so customers can identify the store.
- Show assigned rider's name in the Owner order conversation list.
- Add Owner-side Track rider action after rider assignment.
- Share rider GPS while Assigned and Picked Up, independent of the currently open Rider page.
- Show a live map with a moving rider marker for Customer and Owner; map auto-follows incoming GPS.
- Use per-tab session storage for login tokens, allowing separate roles in separately opened tabs.

Run from the project root with `npm install`, then `npm install --prefix client`, `npm install --prefix server`, and `npm run dev`.
