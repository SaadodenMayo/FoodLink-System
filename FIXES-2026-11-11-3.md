# FoodLink fixes — 2026-11-11 (private chat, GCash, dark hover)

- Replaced the shared order group chat with three independent private conversations per order: Customer ↔ Owner, Customer ↔ assigned Rider, and Owner ↔ assigned Rider.
- Server message retrieval, sending, and reactions now validate the conversation participants. New-message socket events are sent only to the two participants in that private conversation.
- Customer wallet cash-in now presents GCash only; the Manual Demo selector has been removed and the server records the method as GCash.
- Cash-in remains a simulated/demo credit. A real GCash payment gateway is not connected in this project.
- Dark-mode button hover surfaces use the orange accent with white text for contrast.

Existing dashboard and page layouts were retained.
