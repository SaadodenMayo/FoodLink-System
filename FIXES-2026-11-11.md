# FoodLink update — 2026-11-11

## Fixes in this build
- Customer can add a food by clicking the food card, the plus control, or Add to cart.
- Checkout now prevents duplicate submissions and shows the API's error message if an order fails.
- Customer profile refresh now reloads the authenticated profile as well as food, order, notification, and message data.
- Owner profile updates propagate the current business name, owner name, and logo to existing food listings, so customers see the latest store branding.
- Profile save has a loading guard and visible success/error feedback.
- Rider chat room labels identify the food owner and customer for assigned deliveries.
- API validates order quantities and returns a useful message when cart items are empty or no longer available.

## Run
From the project root:
1. `npm install`
2. `npm install --prefix client`
3. `npm install --prefix server`
4. `npm run dev`

Open `http://localhost:5173`.
